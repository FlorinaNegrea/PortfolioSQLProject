Northwind SQL Analysis 📊 
📌 Project Overview

This project is a structured SQL analysis of the Northwind Traders dataset, focusing on business insights related to sales, customers, employees, and suppliers. The dataset consists of multiple relational tables, allowing for complex queries and in-depth data exploration.

🛠 Dataset Structure

The Northwind Traders dataset consists of multiple relational tables. This project specifically utilizes the following:

Orders 📦 – Contains details about customer orders, including OrderDate, OrderID, and CustomerID.

Customers 🏢 – Stores information about customers, such as CompanyName and CustomerID.

Employees 👥 – Includes details on employees who process orders, with attributes like EmployeeID, LastName, and Title.

Products 🛒 – Lists available products, including ProductName and ProductID.

Suppliers 🚚 – Contains supplier information, linking products to their vendors.

Order Details 📝 – A junction table that connects orders and products, storing Quantity, UnitPrice, and OrderID.

🔍 Features & Queries

This project covers a wide range of SQL concepts and queries, including:

Basic Data Retrieval - SELECT, WHERE, ORDER BY.

Aggregations & Grouping - GROUP BY, HAVING, COUNT, SUM, AVG.

Joins & Relationships - INNER JOIN.

Window Functions - RANK, LAG, PARTITION BY.

Common Table Expressions (CTEs) for hierarchical data.

Temporary Tables & Stored Procedures for dynamic queries.
